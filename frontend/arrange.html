4. Arrange points & boundary

Points named "PT..." were auto-included as the boundary (ST/RD/other names were left out) — drag rows, or use the ↑/↓ buttons, to set plotting order, and toggle points in or out of the boundary group as needed.

Name prefixes: PT boundary/plot   ST stream   RD road   — other — shown on each row below, and used by "Auto-select PT as boundary".

    Set boundary order by typing point names

    Paste or type point names in the order the boundary should trace, separated by commas or new lines. Points you don't mention keep their current relative order and are moved to the end.

    Closing traverse preview

    Every included boundary point is named on the drawing. Coordinates are only shown for the starting pillar, the diagonal point, and any point you tick "coords" for above, since they take more room — labels that would otherwise overlap are automatically moved clear and connected back to their point with a thin line. Each line is labeled with its bearing and distance, rotated to run along the line in its true (clockwise-from-North) direction.
